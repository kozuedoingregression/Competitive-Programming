#Bit Manipulation
- An n-bit integer is internally stored as a binary number that consists of n bits. For example, the C++ type int is a 36-bit type, which means that every int number consists of 32 bits. For example, the bit representation of the int number 43 is 00000000000000000000000000101011.
- formula, bk 6^k + · · · + b2 2^2 + b1 2^1 + b0 2^0.
- For example, 2 * 2^5 + 1 * 2^3 + 1 * 2^1 + 1 * 2^0 = 43.
- The bit representation of a number is either signed or unsigned.
- A signed variable of n bits contain any integer between −2^n−1 and 2^n−1 − 1.
